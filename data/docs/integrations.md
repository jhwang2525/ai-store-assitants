# Integrations & API

## Calendar
Connect Google Calendar or Outlook in Settings > Integrations to create a meeting note from any calendar event with one click.

## Web clipper
The Nimbus web clipper browser extension saves a full page, a selection, or a simplified article view into any notebook. It is available for Chrome, Firefox and Edge.

## Import
You can import notes from Evernote (.enex files), Notion (Markdown export), and plain Markdown or text files. Imports keep tags but not reminders.

## REST API
Pro and Team users can create a personal API token in Settings > Developer. The API lets you read, create and update notes. Rate limit: 60 requests per minute per token.

## Zapier
The Zapier integration can create a note when something happens in another app, for example saving every starred email as a note. It requires the Pro or Team plan.
